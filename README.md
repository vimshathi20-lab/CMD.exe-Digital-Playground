# CMD.exe — Digital Playground

**The command line just got a little more interesting.**

What if your Command Prompt was more than just a place to type commands?

CMD.exe is an interactive Windows Batch playground where you can explore mini-games, visual effects, ASCII art, and fun terminal experiences — all through simple commands.

One terminal. Multiple experiences. Endless curiosity.

## ⚡ Getting Started

Ready to enter the terminal?

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd CMD.exe
```

### 3. Launch the playground

```bash
main.bat
```

### 4. Explore the commands

Once the terminal starts, type:

```text
help
```

Discover the available commands and start exploring!
